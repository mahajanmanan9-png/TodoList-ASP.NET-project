TO-DO LIST - ASP.NET CORE MVC

Requirements:
- Visual Studio 2022 or .NET 8 SDK

How to run:
1. Extract the ZIP.
2. Open TodoList.csproj in Visual Studio.
3. Press F5 or Ctrl+F5.
4. The app opens at /Todo.

Features:
- Add task
- Mark task as completed
- Delete task

Note:
This tiny project stores tasks in memory, so tasks reset when the application restarts.
